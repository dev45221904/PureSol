# PureSol

Just a personal practice repo for learning Solidity — messing around with contracts, testing ideas, breaking things, and figuring out why they broke.

Not production code. Not audited. Not meant to be used anywhere real. Just reps.

## What's in here
Random `.sol` files covering things like:
- State variables, mappings, structs
- Payable functions & ETH transfers (`call`, `transfer`)
- Access control patterns
- Common bugs (and the fixes for them)
- Chainlink price feed integration
- General DSA-style practice translated into Solidity

## Why
Because the best way to actually learn Solidity is to write bad contracts, find out why they're bad, and fix them — over and over.
